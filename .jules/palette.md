## 2024-05-24 - Accessibility attributes for React Native TouchableOpacity
**Learning:** Icon-only components using `TouchableOpacity` require both `accessibilityRole="button"` and `accessibilityLabel` attributes to be fully accessible for screen readers in React Native.
**Action:** Always add `accessibilityRole="button"` and `accessibilityLabel` to icon-only `TouchableOpacity` components to ensure they are accessible.
