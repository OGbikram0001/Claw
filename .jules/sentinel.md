## 2024-05-18 - Fix Overly Permissive CORS Configuration and Unsafe Environment Variables
**Vulnerability:** The application was configured with `allow_credentials=True` and `allow_origins=["*"]` in CORSMiddleware, which is a critical security vulnerability and violates the CORS specification (often rejected by modern browsers). It also directly accessed environment variables with dictionary access (`os.environ['MONGO_URL']`), leading to application crashes or unsafe fallback behavior.
**Learning:** Hardcoded wildcard `["*"]` combined with `allow_credentials=True` exposes the API to CSRF or data exfiltration from any origin, especially in FastAPI. Unsafe dictionary access for environment variables violates failing securely.
**Prevention:** Always use `os.environ.get()` with safe defaults for environment access. For CORS, dynamically parse an `ALLOWED_ORIGINS` environment variable (falling back to an empty list `[]` to fail securely) and pass that specific list to `allow_origins`.
