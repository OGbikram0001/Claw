## 2024-06-18 - Overly Permissive CORS and Unsafe Environment Variable Access
**Vulnerability:** The FastAPI backend used a wildcard `allow_origins=["*"]` with `allow_credentials=True`, which is insecure and invalid per CORS specification. Environment variables (`MONGO_URL`, `DB_NAME`) were accessed using direct dictionary access `os.environ['...']` which can crash the application if missing.
**Learning:** `allow_credentials=True` combined with a wildcard origin completely bypasses Same-Origin Policy protections, allowing malicious sites to make authenticated cross-origin requests. Using direct dict access for env vars fails insecurely by crashing the app instead of handling the absence gracefully.
**Prevention:** Configure `allow_origins` securely by reading a comma-separated list from an environment variable (`ALLOWED_ORIGINS`). Access environment variables defensively using `os.environ.get()` with fallbacks, ensuring the application fails securely or provides meaningful configuration errors.
