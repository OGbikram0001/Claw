## 2024-05-18 - Overly Permissive CORS and Unsafe Environment Variable Access
**Vulnerability:** FastApi `CORSMiddleware` was configured with `allow_origins=["*"]` while `allow_credentials=True`. Additionally, environment variables `MONGO_URL` and `DB_NAME` were accessed directly via dictionary lookup `os.environ['...']`.
**Learning:** Using a wildcard `*` for `allow_origins` when credentials are allowed is explicitly blocked by many modern browsers due to security risks. Accessing environment variables using dictionary lookup risks causing application crashes if the variables are unconfigured in the production or development environments, violating the "fail securely" principle.
**Prevention:** Always parse CORS `ALLOWED_ORIGINS` from environment variables, avoiding `*` when credentials are allowed. Default to an empty list `[]` to fail securely. Use `os.environ.get('VAR', default)` for all environment variables to ensure application stability when configurations are missing.
