## 2024-06-06 - Overly Permissive CORS and Unsafe Environment Variable Access
**Vulnerability:** The backend FastAPI application was configured with `allow_origins=["*"]` when `allow_credentials=True` was set, which is an invalid and insecure configuration that could lead to Cross-Origin Resource Sharing vulnerabilities. Additionally, environment variables `MONGO_URL` and `DB_NAME` were accessed using direct dictionary lookup (`os.environ['...']`), which fails insecurely with a KeyError if variables are unconfigured.
**Learning:** The default setup prioritized ease of local development over secure defaults. The codebase lacked an explicit list of trusted origins and did not gracefully handle missing environment variables.
**Prevention:** Always restrict `allow_origins` to a specific list of trusted domains when `allow_credentials=True`. Configure these via environment variables, defaulting securely to an empty list `[]` to ensure no cross-origin access is permitted by default. Use `os.environ.get()` with secure fallback defaults for environment variables to prevent unexpected application crashes. Ensure configuration requirements are documented in an `.env.example` file.
