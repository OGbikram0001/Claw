## 2024-05-31 - [Overly Permissive CORS Configuration]
**Vulnerability:** The FastAPI application was configured with `allow_origins=["*"]` while simultaneously setting `allow_credentials=True`. This is a critical security risk because it allows any website to make requests to the API and include credentials (like cookies or authorization headers), potentially leading to Cross-Site Request Forgery (CSRF) and unauthorized data access.
**Learning:** This existed because it's a common shortcut during development to bypass CORS errors by allowing all origins. However, when credentials are allowed, the `Access-Control-Allow-Origin` header must not be a wildcard `*`. The middleware should return the specific requesting origin if it is in the whitelist, or omit the header entirely if the origin is disallowed.
**Prevention:** Always use an environment-driven whitelist for `allow_origins` in production, parsed from an environment variable like `ALLOWED_ORIGINS`. Default to an empty list `[]` if not configured to fail securely. Avoid using `["*"]` in production code.
