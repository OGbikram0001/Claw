## 2026-05-29 - Overly Permissive CORS and Insecure Env Var Access\n**Vulnerability:** FastApi CORSMiddleware was configured with `allow_origins=["*"]` while `allow_credentials=True`, and environment variables were accessed via direct `os.environ['...']` which causes startup crashes if unset.\n**Learning:** Default configurations or rapid prototyping setups often leave CORS wide open, which is a critical security risk when credentials (cookies/tokens) are allowed. Direct env var access lacks a fallback mechanism, violating the "fail securely" principle.\n**Prevention:** Always source `allow_origins` from environment variables (e.g., `ALLOWED_ORIGINS`) and default to a restrictive posture (empty list). Use `os.environ.get()` with sensible/safe defaults to handle missing environment variables gracefully.
