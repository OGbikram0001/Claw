## 2024-05-18 - Overly Permissive CORS and Insecure Environment Access
**Vulnerability:** The FastAPI backend used a wildcard `["*"]` for CORS origins with `allow_credentials=True`, which is a critical security vulnerability and violates specifications. Furthermore, the application accessed environment variables directly (e.g. `os.environ['MONGO_URL']`) which can lead to ungraceful application crashes.
**Learning:** Due to how FastAPI and Starlette define CORS configurations, setting credentials to true with a wildcard origin allows malicious sites to access user sessions. Explicit whitelists are necessary. Relying on dictionary syntax for env vars causes hard crashes on startup when they are absent instead of failing securely or providing fallbacks.
**Prevention:** Always restrict CORS `allow_origins` to a configured specific whitelist read from the environment, defaulting to an empty list `[]` to fail securely. Access environment variables using `os.environ.get()` with appropriate defaults.
