## 2024-05-20 - Ensure API Endpoints Default to Secure State
**Vulnerability:** The FastAPI backend used a wildcard `*` for `allow_origins` in `CORSMiddleware` while `allow_credentials` was `True`, creating a risk where any website could potentially make authenticated requests on behalf of a user. Furthermore, critical startup parameters like `MONGO_URL` were accessed using direct dictionary lookups (`os.environ['VAR']`), which crashes the application insecurely when unconfigured instead of handling the failure gracefully or defaulting safely.
**Learning:** Security misconfigurations often happen because default wildcard settings are easy for development but dangerous for production. Additionally, relying on the environment strictly having variables set without safe fallbacks (`os.environ.get()`) makes the app brittle and prone to denial-of-service or unhandled exception states.
**Prevention:** Always require explicitly defined allowed origins for CORS (e.g., via `ALLOWED_ORIGINS` environment variable) and default to empty lists `[]` if unconfigured. Never use wildcard `*` origins with credentials. For environment variables, use `os.environ.get('VAR', default_value)` to ensure the app fails securely or falls back safely when not configured.
