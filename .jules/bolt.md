## 2024-11-20 - Prevent re-render cascades in chat/list views
**Learning:** In complex chat or list views where the parent state changes frequently (like `inputText` tracking every keystroke), passing mapping objects (e.g., `expandedTools={expandedTools}`) or inline functions to child list components prevents `React.memo` from working correctly because objects/functions are recreated on each render, causing a cascade of unnecessary re-renders for every single message on the screen.
**Action:** Heavily utilize `React.memo` for list item components. For their props, pass specific primitives (e.g., `isToolExpanded={!!expandedTools[m.id]}`) instead of large mapping objects, and wrap all prop handlers (`toggleTool`, `onApprove`, `onReject`) in `useCallback` to preserve reference stability across re-renders.
