## 2024-05-24 - Prevent React Render Cascades in Complex List Views
**Learning:** In complex chat interfaces, state updates that occur very frequently, such as user keystrokes in a text input field, can inadvertently trigger a complete re-render of large lists (`UserBubble`, `AgentBubble`) if they are coupled in the same component. In addition, passing an entire object mapping (like `expandedTools`) or unmemoized inline functions to child items breaks `React.memo` reference checks, forcing re-renders regardless.
**Action:** When working with large sets of list items that include complex rendering (e.g. Chat Interfaces with multiple Block types), heavily employ `React.memo` on the item components. Ensure props are simple primitives (e.g., boolean `isExpanded={!!state[id]}`) and utilize `useCallback` to enforce reference stability for event handlers. Avoid inline closures in `.map` loops.
