## 2024-06-05 - Avoid Passing Large Objects Directly as Props
**Learning:** State co-location in complex list/chat interfaces with frequent state updates (like `input` fields for typing) can cause severe cascading re-renders in large lists if component instances recreate their inline functions or large data objects are passed as props on every keystroke. Even though it is possible to memoize a component, if its props are changed every keystroke (e.g. by an inline function or referencing a whole new copy of an object) the memoization breaks.
**Action:** Always heavily utilize `React.memo` for list items, extract inline event handlers in parents using `useCallback`, and pass specific primitives instead of large dictionary objects as props (e.g., passing `!!expandedTools[m.id]` instead of the entire `expandedTools` dictionary object) to preserve reference stability and guarantee that memoized child components actually skip re-rendering.
