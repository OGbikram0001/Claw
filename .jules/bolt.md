## 2024-05-14 - Preventing React Re-render Cascades in Complex List Views
**Learning:** In complex chat views containing many intricate list items (e.g., `AgentBubble`, `UserBubble`), passing dynamically generated objects (like `expandedTools` map) or inline functions (`toggleTool`, `onApprove`, `onReject`) to each child causes mass re-renders on every parent state update (e.g., during high-frequency typing in the input box).
**Action:** When working on complex lists where children manage local/interactive state, always wrap list item components in `React.memo`, pass required state as boolean primitives (e.g., `isToolExpanded={!!expandedTools[m.id]}` instead of the full object map), and memoize event handlers with `useCallback` to preserve reference stability and prevent unnecessary deep render cycles.
